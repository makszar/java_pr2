# Практическая работа 2

Автор: Зарубин Максим Сергеевич, РТУ МИРЭА.

Требуется JDK 17 или новее. Сторонних библиотек нет.

В IntelliJ IDEA открой папку проекта, выбери JDK и отметь `src` как Sources Root. Запускай нужный класс через его метод `main`.

Из терминала: `sh build.sh` в Linux или `build.bat` в Windows. Затем `java -cp out имя.класса`.

| Класс для запуска | Задание |
| --- | --- |
| `ru.mirea.pr2.TestAuthor` | Author по UML: конструктор, геттеры, изменение почты, toString |
| `ru.mirea.pr2.TestBall` | Пример Ball из методички: координаты, перемещение и скорость |

Поля Author закрыты. Имя и пол задаются при создании объекта, менять можно только почту. `toString()` возвращает строку вида `Максим Зарубин (M) at max@example.com`.

У Ball есть перемещение на заданное расстояние `move(xDisp, yDisp)`. Дополнительно `setXYSpeed` задает скорость, а `move()` перемещает мяч на эту величину. Так поддерживаются и UML, и текстовое описание из методички.
