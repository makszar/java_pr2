## Как работает код

### Автор книги

Класс `Author` хранит имя автора, электронную почту и пол. Эти значения передаются конструктору при создании объекта:

```java
Author author = new Author("Максим Зарубин", "max@example.com", 'M');
```

Все поля закрыты через `private`. Получить их значения можно методами `getName()`, `getEmail()` и `getGender()`. Изменить почту позволяет `setEmail()`. Имя и пол задаются один раз: для них нет сеттеров, а сами поля объявлены как `final`.

Метод `toString()` возвращает понятное описание объекта:

```text
Максим Зарубин (M) at max@example.com
```

В `TestAuthor` создается автор, выводится его описание, затем меняется почта. После этого значения полей выводятся через геттеры. Так проверяется создание объекта и доступ к его данным.

### Движение мяча

Класс `Ball` описывает мяч на плоскости. Он хранит координаты `x`, `y` и скорость перемещения по каждой оси.

У класса есть два конструктора. Конструктор без параметров оставляет координаты равными нулю. Конструктор с двумя параметрами задает начальное положение мяча.

Методы `setX()` и `setY()` меняют отдельные координаты, а `setXY()` задает обе сразу. Метод `move(xDisp, yDisp)` прибавляет переданные смещения к текущим координатам.

Например, мяч в точке `(100, 100)` после вызова `move(30, 15)` окажется в точке `(130, 115)`.

Также реализованы `setXYSpeed()` и `move()` без параметров. Первый метод задает скорость, второй перемещает мяч на сохраненные значения скорости. Такое решение учитывает и диаграмму, и текстовое описание примера.

## Какие классы и объекты используются

| Класс | Что описывает или проверяет |
| --- | --- |
| `Author` | Автора с именем, почтой и полом |
| `TestAuthor` | Создание автора, изменение почты и работу геттеров |
| `Ball` | Мяч с координатами и скоростью |
| `TestBall` | Создание и перемещение мяча, изменение координат |

В `TestAuthor` создается один объект автора. В `TestBall` создается мяч с заданными координатами и отдельный мяч с координатами по умолчанию. Каждый объект хранит собственные значения полей.

## Какие принципы используются

В работе показана инкапсуляция: поля скрыты, а взаимодействие с объектом происходит через методы. Конструкторы задают начальное состояние объекта. Перегрузка позволяет иметь несколько конструкторов и два варианта метода `move()` с разными параметрами. Переопределение `toString()` делает вывод объектов читаемым.

UML-диаграмма служит схемой класса: на ней указаны его имя, поля, методы и их типы. Обозначение `-` соответствует закрытому доступу `private`, а `+` соответствует открытому доступу `public`.

## Запуск

Нужен JDK 17 или новее. В IntelliJ IDEA следует выбрать JDK и отметить папку `src` как Sources Root. Запуск выполняется через `main` в `TestAuthor` или `TestBall`.

Сборка из терминала: `sh build.sh` в Linux или `build.bat` в Windows.

```bash
java -cp out ru.mirea.pr2.TestAuthor
java -cp out ru.mirea.pr2.TestBall
```
